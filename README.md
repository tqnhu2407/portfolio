# Tran Quynh Nhu — Portfolio

Personal portfolio for Tran Quynh Nhu, an AI Engineer working on AI Highlight Detection, applied AI, multimodal models, and research-to-production engineering.

The current visual direction is **Ocean Bloom**: a soft, expressive combination of ocean blue and coral pink.

## View locally

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## Main files

- `index.html`: content and page structure
- `ocean-bloom.css`: main visual style
- `script.js`: subtle reveal interactions
- `assets/`: favicon and social preview image
- `vercel.json`: Vercel configuration

Two earlier visual explorations, Rosewave and Pink Editorial, are kept in the repository for reference.

For beginner-friendly editing and deployment instructions, see [`HUONG_DAN.md`](HUONG_DAN.md).
